# Камешек

Виртуальный питомец для Windows 10 и 11 (x64). Portable-файл запускается двойным кликом без установки и работает офлайн.

## Скачать готовый .exe

### Из GitHub Actions

1. Войдите в GitHub и откройте вкладку [Actions](https://github.com/getfers/stone/actions/workflows/build.yml).
2. Выберите успешный запуск **Windows portable** для ветки `main`.
3. Прокрутите страницу запуска до раздела **Artifacts** и скачайте **Stone-Windows-x64**.
4. Распакуйте скачанный ZIP и дважды щёлкните по `Stone-Windows-x64.exe`.

Артефакты Actions хранятся 30 дней. Тот же файл можно скачать напрямую в разделе **Assets** нужной сборки на странице [Releases](https://github.com/getfers/stone/releases).

## Режимы

| Режим | Как работает |
| --- | --- |
| **Оверлей** | Камешек ползает по всему монитору, на котором находился указатель при выборе режима. Прозрачное окно находится поверх остальных окон. Клики по пустой области проходят в программы под ним. |
| **Мини-виджет** | Небольшое окно поверх других окон в правом нижнем углу рабочего стола. |
| **Полное окно** | Обычное окно с площадкой и постоянно открытой панелью питомца. |

Нажмите на камешек, чтобы погладить его, или переместите его мышью. В мини-виджете панель открывается кнопкой **Уход**, а на рабочем столе — правым щелчком по камешку. Режим окна и настройку самостоятельного движения можно поменять через меню **Режимы** или значок в области уведомлений Windows.

- **Уход.** Следите за бодростью, сытостью, жаждой, настроением, чистотой и интересом. Камешек сам пьёт воду, просит еду, играет и засыпает, когда устаёт или наступает ночь. Его можно уложить и разбудить вручную. Самостоятельные действия и сон проходят без звуков.
- **Гардероб.** Надевайте и снимайте аксессуары, выбирайте комнату для полного окна и мини-виджета. Время суток следует системным часам или задаётся вручную.
- **Прогулки.** Лес, пикник и пляж оформлены по-разному. По возвращении камешек рассказывает, что увидел, и может принести аксессуар.
- **Игры.** Запоминайте перестановки в «Трёх напёрстках», ловите искры за 15 секунд или управляйте камешком в «Ловить роллы» стрелками и мышью. Завершённые игры поднимают настроение.

## Органайзер и трей

- В **Заметках** можно хранить текстовые записи и назначать им дату и время. Когда подойдёт срок, камешек появится поверх окон с текстом заметки.
- В **Будильниках** можно выбрать время, дни недели, подпись и один из трёх сигналов с предварительным прослушиванием. Без выбранных дней будильник сработает один раз. Звонок продолжается до отключения или отсрочки на пять минут.
- Через значок камешка в трее можно переключить режим, открыть органайзер, включить **Автозапуск с Windows** или завершить работу приложения. Крестик сворачивает окно питомца в трей. При автозапуске программа сразу работает в трее.
- Когда компьютер выходит из сна или приложение снова запускается, камешек показывает пропущенные напоминания и будильники. Несколько событий одного повторяющегося будильника за время отсутствия объединяются в одно.

Прогресс питомца, гардероб, заметки, будильники и настройки хранятся в папке Electron `userData` (обычно `%APPDATA%\Камешек`). При замене portable-файла прогресс берётся из той же папки.

## Запуск из исходников и сборка

На Windows установите Node.js 24 и выполните:

```sh
npm ci
npm test
npm start
npm run build
```

После сборки готовый файл находится в `dist/Stone-Windows-x64.exe`. GitHub Actions собирает его при каждом пуше в `main` и публикует в Artifacts и Releases. Для pull request в `main` сборка доступна в Artifacts.

Код окон, трея и сохранения настроек находится в `electron/`. Модель питомца, отрисовка, интерфейс и занятия находятся в отдельных модулях в `renderer/`.
