# Камешек

Виртуальный питомец для Windows 10 и 11 (x64). Portable-файл запускается двойным кликом без установки и работает офлайн.

## Скачать готовый .exe

### Из GitHub Actions

1. Войдите в GitHub и откройте вкладку [Actions](https://github.com/getfers/stone/actions/workflows/build.yml).
2. Выберите успешный запуск **Windows portable** для ветки `main`.
3. Прокрутите страницу запуска до раздела **Artifacts** и скачайте **Stone-Windows-x64**.
4. Распакуйте скачанный ZIP и дважды щёлкните по `Stone-Windows-x64.exe`.

Артефакты Actions хранятся 30 дней. Тот же файл можно скачать напрямую в разделе **Assets** нужной сборки на странице [Releases](https://github.com/getfers/stone/releases).

## Режимы

| Режим | Как работает |
| --- | --- |
| **На рабочем столе** | Камешек ползает по всему монитору, на котором находился указатель при выборе режима. Прозрачное окно находится поверх остальных окон. Клики по пустой области проходят в программы под ним. |
| **Мини-виджет** | Небольшое окно поверх других окон в правом нижнем углу рабочего стола. |
| **Полное окно** | Обычное окно с площадкой и занятиями. В игре «Ловить роллы» используйте стрелки или перетаскивайте камешек мышью. |

Нажмите на камешек, чтобы погладить его, или переместите его мышью. Чтобы сменить режим, нажмите **Режимы** в окне, щёлкните правой кнопкой по камешку или откройте контекстное меню его значка в области уведомлений Windows. Там же можно отключить самостоятельное движение или выбрать **Выйти**. Настройка движения сохраняется между запусками.

## Запуск из исходников и сборка

На Windows установите Node.js 24 и выполните:

```sh
npm ci
npm start
npm run build
```

После сборки готовый файл находится в `dist/Stone-Windows-x64.exe`. GitHub Actions собирает его при каждом пуше в `main` и публикует в Artifacts и Releases. Для pull request в `main` сборка доступна в Artifacts.

Код окон, трея и сохранения настроек находится в `electron/`. Модель питомца, отрисовка, интерфейс и занятия находятся в отдельных модулях в `renderer/`.
